# Assignment 2-3 Part B – IDE Features Reflection

## Introduction

This assignment was my first time writing, running, and testing code in an IDE. I used Visual Studio Code through the Codio virtual machine, which put everything I needed for my first programming assignment in one place. In this reflection, I discuss three features that stood out to me: syntax highlighting, the Problems panel, and the integrated terminal. Learning to use IDE features like these helps beginning programmers because they make code easier to read, point out mistakes early, and make testing part of the writing process.

## Feature 1 – Syntax Highlighting

Syntax highlighting is a feature that displays different parts of my code in different colors, such as keywords, strings, and variable names. While working on my assignment, it kept my code looking clean and organized, and it made it easy to tell where each piece of code started and ended. Because I could recognize each part at a glance, I could read through my program faster and spot things that looked out of place. For a beginning programmer, this visual structure makes code far less overwhelming to read.

## Feature 2 – Problems Panel

The Problems panel is a section of VS Code that collects all of the errors and warnings in my code in one place. When something in my program didn?t work properly, it told me where to go to find the issue, so I didn?t have to search through every line. It also let me know when I was missing syntax or had misspelled something, which were the kinds of small mistakes I was most likely to make as a beginner. Being pointed straight to the problem saved me time and made fixing errors feel manageable instead of frustrating, which is valuable for anyone just learning to code.

## Feature 3 – Integrated Terminal

The integrated terminal is a built-in command line inside VS Code that lets me run my program without leaving the editor. As I wrote my code, I used it to test each line in real time, which let me check that my formatting was correct and that my program produced the right outputs. Catching problems right after writing a line, instead of waiting until the whole program was finished, made errors much easier to track down and fix. For a beginning programmer, having writing and testing in one place builds good habits and makes the process feel less intimidating.

## Conclusion

Using VS Code for this assignment showed me how much an IDE can support a new programmer. Syntax highlighting kept my code clean and easy to read, the Problems panel guided me to errors and misspellings, and the integrated terminal let me test my work as I wrote it. Together, these features made it easier to find and fix mistakes and to confirm that my program produced the right output. I plan to keep using them in future assignments, and knowing how to rely on my tools gives me more confidence as I continue learning to program.
